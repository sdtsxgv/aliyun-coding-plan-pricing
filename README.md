## 订阅与配置：四步走，三个坑

下单流程本身不复杂，按官方文档走完四步就能用：

1. **订阅套餐**：在购买页选Pro下单。用RAM子账号操作的话，需要主账号先授权；名额售罄就等第二天9:30补充。
2. **领取专属API Key**：在Coding Plan页面生成sk-sp-开头的专属Key。这一步最容易出错——套餐Key（sk-sp-开头）和按量付费的通用Key（sk-开头）不通用，配错了要么额度不被扣、要么直接走按量计费。
3. **配置接口地址**：OpenAI兼容协议和Anthropic兼容协议各有一个专属Base URL，按所用工具的文档填，两套地址和Key都不能混用。
4. **接入AI工具**：Claude Code、Cline、Cursor、Qwen Code、OpenClaw等都有官方接入文档，对着配就行。

三个坑再强调一遍：套餐不退款；每次提问消耗的是模型调用次数而非固定1次，复杂任务一轮可能吃掉几十次额度；额度触顶后调用会暂停，赶工时留意5小时窗口的恢复节奏。
